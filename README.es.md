# Liftnote

Plugin de **entrenamientos para Obsidian**, pensado para **iPhone**.

Rutinas, series en vivo, descanso, PRs automáticos, volumen, calendario y progresión.

## Instalar

1. Ajustes → Plugins de comunidad → Desactivar modo restringido
2. Explorar → buscar **Liftnote** → Instalar → Activar

## Uso rápido

1. Icono de la **mancuerna** en la barra lateral
2. Elige una rutina o entreno libre
3. Escribe peso y reps → check verde → descanso
4. Pestaña Calendario para planificar o registrar días pasados

Los datos se guardan en tu bóveda, en `Entrenamiento/`.
